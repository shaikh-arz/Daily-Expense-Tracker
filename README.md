# 💰 Daily Expense Tracker

A simple Python-based application to record, manage, and track daily expenses.

## 📌 About The Project

The **Daily Expense Tracker** helps users keep track of their daily spending. Users can add expenses, view recorded expenses, and monitor their total expenditure.

This project was created using Python and is suitable for beginners who want to practice Python programming and data handling.

## ✨ Features

* ➕ Add daily expenses
* 📋 View expense records
* 💰 Calculate total expenses
* 🗂️ Organize expenses
* 🐍 Built using Python
* 💾 Store expense data

## 🛠️ Technologies Used

* Python
* File Handling
* Functions
* Lists / Dictionaries

## 🚀 How to Run

1. Clone this repository:

```bash
https://github.com/shaikh-arz/Daily-Expense-Tracker
```

2. Open the project folder:

```bash
cd Daily-Expense-Tracker
```

3. Run the Python file:

```bash
python expense_tracker.py
```
